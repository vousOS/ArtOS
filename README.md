## 🌟 Особливості та можливості

- ⚡ **Швидке завантаження:** Мінімалістичне ядро без зайвого навантаження.
- ⌨️ **Власний командний інтерфейс (CLI):** Обробка системних команд через консоль.
- 💾 **Робота з пам'яттю:** Ініціалізація та контроль системних ресурсів під час старт-апу.
- 🔌 **Модульна структура:** Легке підключення нових драйверів пристроїв (клавіатура, дисплей, файлова система).

## 🧠 Архітектура ядра (`Kernel.cs`)

Точка входу операційної системи розміщена у файлі `Kernel.cs`. Життєвий цикл ядра складається з трьох основних етапів:

1. **`BeforeRun()` — Ініціалізація:**
   - Налаштування відеорежиму (текстовий/VGA).
   - Підключення та перевірка драйверів клавіатури і базових пристроїв.
   - Виведення привітального банера системи.

2. **`Run()` — Основний цикл (Main Loop):**
   - Очікування та зчитування введення від користувача.
   - Парсинг та виконання команд (командна оболонка).

3. **Обробка помилок та завершення:**
   - Безпечна зупинка системи (`shutdown`) або перезавантаження (`reboot`).
